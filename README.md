# patient-visit-followup-manager
# 🏥 Healthcare Management System (PHP & MySQL)

A simple and complete **Healthcare Management System** developed using  
**PHP, MySQL, HTML, CSS, JavaScript**.

This project helps manage **patients, visits, follow-ups, and reports** with proper validations and calculations.

---

## 📌 Features

### 🔐 Authentication
- Secure login system
- Role-based access (Admin / Doctor / Staff)
- Proper error handling for wrong username & password

### 👤 Patient Management
- Add new patients
- Edit patient details
- View patient profile
- Delete patient (with confirmation)
- Age calculation (years & months)
- Phone number validation

### 🏥 Visit Management
- Record patient visits
- Auto follow-up date calculation (+7 days)
- Consultation & lab fee tracking
- Visit history per patient

### 📊 Reports
- Full patient summary report
- Follow-up report (Overdue / Upcoming)
- Monthly statistics report
- Birthday report (next 30 days & milestone ages)
- Patients with zero visits report

### 📈 Calculations & Logic
- Age calculation using DOB
- Days since last visit
- Inactive patients (180+ days)
- Follow-up status detection
- Monthly aggregation using SQL

### 🎨 UI & UX
- Clean dashboard
- Responsive layout
- Centralized CSS using assets folder
- Alerts & status indicators

---
